# ALMAutomation

This repo's plan is to create a standalone server which can pull from the ALM Api and create metrics.

Runs with React/TS/Vite frontend and Node.js backend

`npm install` in root to install the node modules
To run, use 2 terminals
`npm run dev` which launches the frontend at http://localhost:5173
`node src/backend/server.cjs` which launches the backend at https://localhost:3001

Currently just a proof of concept and is not secure.
